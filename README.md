### Featured projects : 

| Project | Overview |
| :--- | :--- |
| **Weakly-Supervised WSI Classification** | Designing a weakly-supervised pipeline using DINOv3 and DistillBERT to classify gigapixel histology slides as healthy/tumoral without patch-level annotations, coupled with an interactive visualization for interpretability. Please note that the code is not currently public on GitHub for confidentiality reasons beyond my control. |
| **Euro Coin Detection & Classification** | Combining Hough Circle Transform and Watershed segmentation to detect overlapping coins, followed by HSV color-space rule classification to accurately identify, value, and count Euro coins in varied lighting conditions. |
| **Comparative Shape Classification** | Benchmarking 5 geometric descriptors (E34, GFD, SA, F0, F2) using k-NN, k-means, and a majority-voting ensemble to robustly classify binary shapes under noise, occlusions, and intra-class variability. |
| **Hybrid Information Retrieval Engine** | Combining lexical (BM25+) and semantic (SentenceTransformers) rankings via Reciprocal Rank Fusion, with a supervised SVM reranking module to deliver highly relevant results for 216k technical documents. |
| **Robust Music Identification Pipeline** | Building a two-stage identification pipeline using FAISS-based vector search (CLAP/MERT embeddings) and Shazam-style spectral fingerprinting to robustly identify songs from short microphone recordings, enhanced with RIR augmentation. |
